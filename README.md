## Tech
PHP, HTML, CSS, JavaScript (no database; users are saved in `data/users.json` with hashed passwords)

## Features
- Login and Registration pages with navigation between them
- Required fields, email format, password rules, password confirmation
- Error and success messages
- Show/hide password, Remember me
- Safe input handling (escaping, password hashing, CSRF token)

## How to run
1. Install XAMPP and start Apache.
2. Copy this folder into `C:\xampp\htdocs\`.
3. Open http://localhost/Silveron_Cassandra_LabExam/
